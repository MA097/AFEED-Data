# AFEED-Data
Public, reviewed brand metadata for AFEED. No application code, credentials, user data, or unreviewed research outputs.

- `manifest.json`: catalog revision and feed location.
- `brand_catalog.json`: sourced brand/product-family metadata only; not durability, reliability or model certification.

Updates are published from the private AFEED-Research repository after review. The app can download these files without authentication. Automated cross-repository publishing is not enabled until a restricted publisher credential is configured.
